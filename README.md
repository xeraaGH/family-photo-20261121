A warm evening kitchen: a family of three relaxed around the table while the
household robot peels a carrot at the counter. Dog bowl on the floor, laundry
on the radiator.

## Run

```sh
node main.ts
```

Writes `entry.png` (1024x1024) to `$MAKEFUN_OUTPUT_DIR` or `/output`.
